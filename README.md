# ESP32-HUB

Устройство на базе ESP32-S3 (в моём случае N16R8, платы без дополнительной RAM могут не работать из-за недостатка оперативной памяти): экран 240×320, пять кнопок, Wi-Fi, BLE и т.д. Поддержка других плат планируется, но пока что её нет.

Прошивка на MicroPython, собирать ничего не нужно — всё лежит в `src/` и заливается
на плату как есть.

Взаимодействие с платой двумя способами:

- **Classic UI** - интерфейс на экране устройства
- **Web UI** - поднятие сервера в локальной сети для взаимодействия с устройством через браузер

## Приложения

- wifi (подключение к wifi)
- ble (подключение по ble, пока что работает криво)
- explorer (web проводник для управления файлами)
- MIDI (для музыкантов может быть полезно)

## Железо

| Что | Пины |
|-----|------|
| ILI9341, SPI2 60 МГц | sck 12, mosi 11, miso 13, cs 10, dc 3, rst 14, led 46|
| Кнопки (PULL_UP, нажатие подсоединяет к GND) | право 17, лево 16, верх 7, низ 15, выбор 18 |
| SD карта | пока что не назначены |


SD-карта поддерживается кодом (в теории, пока что работу с ней не проверял), но по умолчанию выключена (`SD_ENABLED = False`).

## Структура

```
src/
  boot.py                 запуск, монтирование SD (если включена)
  main.py                 лаунчер: Web UI / Classic UI / Power off
  config.py               размеры экрана, цвета, часовой пояс, статус-бар
  hardware_setup.py       SPI, дисплей, кнопки

  core/                   реестр приложений, пиксельный UI, статус-бар,
                          питание и сон, логи, NTP, экранная клавиатура

  drivers/                ILI9341 и палитра (вендорные)
  gui/                    micro-gui: Screen, Widget, Listbox, Button
  lib/                    все остальные библиотеки
  apps/system/            системные приложения
  apps/user/              пользовательские приложения
  web/                    главные страницы web сервера

models/                   модели для 3D печати
```

Приложение — это папка `src/apps/<system|user>/<name>/` с `app.py` (экран платы),
`app_web.py` (веб-версия) и общей папкой `utils/`. Реестр сам находит папки с `app.py`,
поэтому список приложений в меню править не нужно.

## Установка

1. Прошить плату на MicroPython для ESP32-S3.
2. Скопировать содержимое `src/` в корень файловой системы платы — проще всего через расширение для VSCode или mpremote:

   ```
   cd src
   mpremote connect COM6 fs cp -r * :
   mpremote connect COM6 reset
   ```

3. Порт поменять на свой (`COM7`, `COM11` и т.д.).

После перезагрузки появится главная страница. Web UI включается из меню: плата поднимает точку доступа или подключается к сохранённой сети, адрес показывается на экране.

## Настройка

- `src/config.py` — часовой пояс, цвета, геометрия, `DEBUG_LEVEL`;
- `src/apps/system/explorer/config.py` — `WEB_PASSWORD`, `AP_PASSWORD`, `AP_SSID`.
  **Пароли в репозитории — дефолтные. Смените их перед тем, как включать точку доступа
  в людном месте.**
- `src/apps/user/midi/config.py` — доступные пины, канал по умолчанию;

## Заметки

- `hardware_setup` импортируется первым: он поднимает SPI и дисплей.
- Реестр приложений кеширует список в RAM. Если папка появилась после старта,
  нужен `app_registry.invalidate()`.
- Долгие операции — в `asyncio.create_task`, иначе интерфейс замирает.
- Пресеты и состояние питания хранятся на флеше и в git не попадают (см. `.gitignore`).
