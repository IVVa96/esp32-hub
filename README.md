# ESP32-Hub

Карманный мультитул на ESP32-S3: экран 240×320, пять кнопок, Wi-Fi, BLE и USB-MIDI.
Прошивка на MicroPython, собирать ничего не нужно — всё лежит в `src/` и заливается
на плату как есть.

Управление с двух сторон:

- **Classic UI** — пиксельный лаунчер на самом экране платы;
- **Web UI** — портал в браузере по Wi-Fi: веб-версии приложений, файловый менеджер,
  запуск и выключение платы.

## Приложения

| Приложение | Источник | Что делает |
|---|---|---|
| MIDI | user | MIDI-контроллер: USB и BLE, выбор пинов, каналы и CC, пресеты. Веб-версия — control surface с фейдерами, кнопками, переключателями и пэдами, раскладка перетаскивается |
| Clock | user | Полноэкранные часы, циферблаты подключаются из `utils/faces/`, время по NTP |
| Wi-Fi | system | Сканер сетей, подключение, сохранённые пароли, точка доступа |
| BLE | system | Сканер BLE-устройств, плата работает как central |
| Explorer | system, web | Портал и файловый менеджер: загрузка, скачивание, переименование, удаление, USB-tool |
| Radio Scanner | user | Спектр 2.4 ГГц: столбики по Wi-Fi каналам 1–13 с маркерами пиков |
| IMCD P2P | user | Заготовка дальнобойной связи: nRF24L01+ (2.4 ГГц) плюс CC1101 (433 МГц), пины и режимы уже расписаны, драйверов пока нет |

## Железо

| Что | Пины |
|---|---|
| ILI9341, SPI2 60 МГц | sck 12, mosi 11, miso 13, cs 10, dc 3, rst 14 |
| Подсветка | 46 |
| Кнопки (PULL_UP, нажатие в 0) | next 17, sel 18, prev 16, inc 7, dec 15 |
| USB / консоль | 19/20 |
| Свободно | 1, 2, 21, 38, 40, 47, 48 (1 и 2 — ADC) |

Под IMCD зарезервированы 4, 5, 6, 8, 9 и SPI3 (39, 41, 42). Если радио не нужно,
их можно вернуть в MIDI, поправив `MIDI_AVAILABLE_PINS` в `src/apps/user/midi/config.py`.

SD-карта поддерживается кодом, но по умолчанию выключена (`SD_ENABLED = False`).

## Структура

```
src/
  boot.py                 запуск, монтирование SD (если включена)
  main.py                 лаунчер: Web UI / Classic UI / Power off
  config.py               размеры экрана, цвета, часовой пояс, статус-бар
  hardware_setup.py       SPI, дисплей, кнопки
  core/                   реестр приложений, пиксельный UI, статус-бар,
                          питание и сон, логи, NTP, экранная клавиатура
  drivers/                ILI9341 и палитра (вендорные)
  gui/                    micro-gui: Screen, Widget, Listbox, Button
  lib/                    aioble и USB-стек (вендорные)
  apps/system/            explorer, wifi, ble
  apps/user/              midi, clock, imcd, radio_scanner
  web/                    portal.html, login.html
models/                   корпус в FreeCAD
```

Приложение — это папка `src/apps/<system|user>/<name>/` с `app.py` (экран платы),
`app_web.py` (веб-версия) и общей папкой `utils/`. Реестр сам находит папки с `app.py`,
поэтому список приложений в меню править не нужно.

## Установка

1. Залить на плату MicroPython для ESP32-S3.
2. Скопировать содержимое `src/` в корень файловой системы платы — проще всего Thonny
   («Файл → Сохранить на устройство») или mpremote:

   ```
   cd src
   mpremote connect COM6 fs cp -r * :
   mpremote connect COM6 reset
   ```

3. Порт поменять на свой (`COM6`, `/dev/ttyACM0` и т.д.).

После перезагрузки появится лаунчер. Web UI включается из меню: плата поднимает
точку доступа или подключается к сохранённой сети, адрес показывается на экране.

## Настройка

- `src/config.py` — часовой пояс, цвета, геометрия, `DEBUG_LEVEL`;
- `src/apps/system/explorer/config.py` — `WEB_PASSWORD`, `AP_PASSWORD`, `AP_SSID`.
  **Пароли в репозитории — дефолтные. Смените их перед тем, как включать точку доступа
  в людном месте.**
- `src/apps/user/midi/config.py` — доступные пины, канал по умолчанию;
- `src/apps/user/imcd/config.py` — пины радио, режим и канал.

## Заметки

- `hardware_setup` импортируется первым: он поднимает SPI и дисплей.
- Реестр приложений кеширует список в RAM. Если папка появилась после старта,
  нужен `app_registry.invalidate()`.
- Долгие операции — в `asyncio.create_task`, иначе интерфейс замирает.
- Пресеты и состояние питания хранятся на флеше и в git не попадают (см. `.gitignore`).

## Чего пока нет

- Драйверы nRF24L01+ и CC1101 — IMCD сейчас только экран-заглушка;
- веб-версия IMCD и шифрование;
- поддержка SD включается вручную и на конкретной разводке не проверялась.
