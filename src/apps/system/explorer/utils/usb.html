USB file explorer file_explorer.py

The file is downloading. This is a standalone PC script: the web interface is built in, no repository or extra files are needed.

Where is the file? If the browser asked for a location, it is there. If not, check the "Downloads" folder. To make the browser ask every time, enable "Ask where to save each file" in Chrome download settings.
DOWNLOAD AGAIN BACK TO EXPLORER
01

Connect the board via USB

Use a data cable, not a charge-only cable. The board must appear in the system as a COM port.

02

Check Python and mpremote

Python 3 for Windows is required. During installation check Add Python to PATH. Then install mpremote:

python -m pip install mpremote

If the python command is not found, try py -m pip install mpremote.

03

Open a terminal in the script folder

For example, if the file is in Downloads:

cd "$env:USERPROFILE\Downloads"

In File Explorer you can open the folder, click the address bar, type powershell, then press Enter.

04

Start the explorer

Find the COM port: Device Manager → "Ports (COM & LPT)". Replace the number below with your port:

python file_explorer.py --port COM6

You can omit the port: python file_explorer.py will try to find the board automatically.

05

Open the interface in the browser

After launch the script prints the address. Open it:

http://127.0.0.1:8081/
06

Finish

Press Ctrl+C in the terminal. USB access stops the board application — when finished press RESET in the web interface or reboot the board.

Important: close Thonny and other programs that hold the COM port. The script runs on the PC, not the board. Wi-Fi downloads may go to "Downloads" without a folder prompt — this is a browser limitation for plain HTTP.
